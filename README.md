📚 BooksBridge

A multi-modal platform for buying, selling, and exchanging books.



🚀 Overview

BooksBridge is a full-stack web application that enables users to perform multiple types of book transactions including direct sales, peer-to-peer exchange, and discovery of unique listings. The platform is designed with a scalable and modular architecture to support real-time interactions and seamless user experience.


⚙️ Tech Stack

  Frontend: Next.js  
  Backend & Database: Supabase  
  State Management: TanStack Query  
  Async Workflows: Upstash QStash  
  Storage: Supabase Storage  


✨ Features

 📦 List books for sale
 🔄 Exchange books via barter system
 🕵️ Mystery book trading (blind exchange)
 ⚡ Real-time updates using TanStack Query
 🔐 Authentication & user management via Supabase
 🖼️ Image upload and storage
 📊 Scalable and modular architecture


🧠 System Design Highlights

 Efficient query invalidation & caching with TanStack Query  
 Event-driven workflows** using QStash  
 Secure and scalable backend powered by Supabase  
 Optimized for low-latency UI updates
